# qtcloud-think（思考云）四端计划

> 记录时间：2026-08-22
> 背景：认知建模简化为两层（心智模型本体 + 情境意识实例层），落地为 4D 认知过程（感知 → 理解 → 预测 → 决策/行动）

| 端 | 当前 | 待办 |
|----|------|------|
| **provider** | Python（FastAPI） | **待重构为 Go**（对齐其他产品云 provider 模式） |
| **studio** | Flutter（旧方案页面） | **最小闭环先行**：感知+理解两页（预测/决策延迟，验证后做） |
| **cli** | Rust（analyze/model/repo 模块已归档，代码断裂） | **待简化**（对齐简化建模——收敛为收集+澄清，移除模糊模型） |
| **site** | 无 | **待增加**（思考云对外介绍页） |

## 实施策略（验证先行）

1. **最小闭环先行**：cli 简化 + studio 感知/理解页——一周内真实用起来
2. **真实使用验证**：用 1-2 周——主动用/缺了难受 = 值得做；砍掉不受影响 = 不值得做
3. **延迟项**：studio 预测/决策页、provider 重构 Go、site——等最小闭环验证后再推进

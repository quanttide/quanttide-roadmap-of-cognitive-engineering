# studio scope

## 范围

思维外脑的交互端——思维收集、澄清对话、知识结构展示。

## 当前状态

- Flutter（android/ios/web/linux）
- 页面基于旧方案（如标注页 annotation_screen），未对齐最新认知模型

## 设计方向（2026-08-22 确认）

**导航 = 4D 认知过程本身**（不发明抽象层，结构即真实）：

```
感知 → 理解 → 预测 → 决策
```

| 导航 | 内容 |
|------|------|
| **感知** | 思维收集输入（想法流、日志）——零门槛，想到就记 |
| **理解** | AI 加工 + 澄清对话（清晰度判断、多轮澄清、结构化）——AI 加工、人类挑选 |
| **预测** | 认知推演（基于情境意识的下一步/趋势） |
| **决策** | 认知判断产出（目标状态确立）——思考云的认知闭环终点 |

**两层建模落地**：
- 心智模型本体（稳定结构树）呈现于理解/预测页
- 情境意识实例（动态想法）按本体挂接
- 反复出现的模式可升级为本体条目（从实例到本体）
